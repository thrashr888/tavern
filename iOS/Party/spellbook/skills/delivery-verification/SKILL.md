# Delivery verification

## When to use

A file, message, link or project update has been delivered or saved.

## Steps

1. Check the saved or sent record for the correct recipient, destination, file version and attachments.
2. Open the resulting item or read back the changed fields.
3. Check intended recipient access without widening sharing.
4. Report exactly what is verified: sent, accessible or acknowledged. A send receipt is not proof of receipt or review.
5. If the outcome is uncertain, inspect before retrying and report the gap.
