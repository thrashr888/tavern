# Artwork creation and handoff

## When to use

A project needs new or revised artwork and a usable handoff.

## Steps

1. Confirm the brief, references, dimensions, transparency and file formats.
2. Create or revise the requested elements, preserving the agreed style.
3. Inspect the final image and check dimensions and formats.
4. Package clearly named, versioned files with short usage notes.
5. Hand off to the approved, verified recipient or destination, then run Delivery verification.
