# Project handoff

## When to use

A project or task moves from one agent to another

## Steps

1. Handing agent writes: goal, current state, done and not done, links, open questions, next step, owner.
2. Post it on the project thread and Linear issue (one thread per project).
3. Receiving agent confirms in writing what it owns and any gaps.
4. Handing agent stays reachable until confirmed.
5. Update the agent owner label.
6. Check the handoff landed (Delivery verification).
