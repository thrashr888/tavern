# Research to recommendation

## When to use

A question needs sources and a call (feasibility, tool choice)

## Steps

1. Read primary sources and note the date read.
2. Separate what you verified from what you guessed.
3. Write it up in a doc with a clear pick and why.
4. Email a 3-line summary plus the link.
5. Name any new access, credential or endpoint as a Needs from Paul item.

Not written yet. Add it at the next Friday review.
