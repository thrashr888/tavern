# Repo change to draft PR

## When to use

Paul says go on code work in one of his repos

## Steps

1. Branch, never the default branch.
2. Run the repo's local checks (Mac apps: scripts/check.sh on the Mac, not GitHub Actions).
3. Push and open a draft PR; assign Paul and request his review.
4. Watch the PR and fix CI and review comments yourself.
5. Paul merges (pi-bundle is the one exception).

Not written yet. Add it at the next Friday review.

## Tools

GitHub, Claude Code

## Permissions

This spell grants no authority. Follow Outward-action check (SB-12) and Paul's standing rules: ask Paul before anything outside the Smithery or anything irreversible, and keep secrets out of mail, docs and repos.

## Notes

Code starts only on Paul's go.
